Training Goals

計畫核心目標

協助團隊建立 AI 協作的標準化流程，從底層架構認知出發，掌握全方位應用。

架構認知

深入理解 Agent 與 MCP 協定，從單純對話進化為精確的任務執行。

Copilot 全制霸

掌握 GitHub Copilot 在 IDE 與 CLI 的進階應用，提升開發效率。

工作流優化

透過分級實作，具體產出企業知識庫或自動化解決方案。

課程大綱 (總時數：4 小時)

SESSION 01

AI 生態系與
協作架構

60 分鐘

目標：建立對現代 AI 架構的系統性認知

課程開場 (10min)

課程目標說明與破冰活動。

"從對話進化為行動，理解 AI 運作的底層邏輯。"

核心概念講解 (50min)
  • AI 的大腦 (LLM)：解析本質與幻覺風險。
  • AI 的翻譯官 (Function Calling)：自然語言轉指令。
  • AI 的手腳 (Agent)：智能代理與 ReAct 模式。
  • AI 的記憶 (RAG)：檢索增強生成，連結企業私有知識庫。
  • AI 的神經系統 (MCP)：模型上下文協定。
SESSION 02

Copilot 商業價值
與 IDE 實戰

60 分鐘

目標：分析導入效益，並演示 IDE 內的高效引導技巧

1. 商業考量 (15min)
  • 服務定價：Business vs Enterprise 功能差異。
  • ROI 分析：評估工時節省與品質效益。
2. IDE 協作實戰 (45min)
  • Ghost Text：註解驅動開發 (CDD)。
  • Chat 應用：@workspace, /fix, /tests。
  • 重構實戰：Legacy Code 轉 Clean Code。
課後任務 (Homework)

請學員回去針對自己的專案，使用 IDE 內建的 GitHub Copilot 嘗試進行一次重構。

SESSION 03

CLI 實戰與
未來展望

90 分鐘

目標：建立標準化工作流，邁向 Agent 流程設計師

1. 環境與 CLI 介紹 (15min)

檢查學員環境安裝狀況，並介紹 GitHub Copilot CLI 的基礎指令與操作介面。

2. 知識管理實戰 (60min)

情境： 使用 CLI 驅動，將散亂文件轉為結構化知識庫。

Agent Prompt 設計 執行任務 除錯與優化 成果驗證
3. 未來展望 (15min)
Coding Agent 直接在 GitHub 上開發的跨時代服務。
Workflow Automation 結合 n8n 與 Agent Builder 的自動化場景。

期末實作任務：專案工作流改造

識別一個重複性高或耗時的流程，利用 GitHub Copilot CLI 設計自動化解法。

1

痛點識別

選擇部署流程、Code Review 格式或測試生成等瓶頸。

2

工作流設計

設計一套結合 CLI 指令的操作標準流程 (SOP)。

3

Agent 實作

建立符合工作流的 Agent Prompt 與指令腳本。

4

成果驗收

提交「工作流改造報告」，對比改善前後效益。

為什麼選擇這個計畫？

不僅是技能培訓，更是團隊工作文化的轉型。

決策依據

提供完整的商業分析，加速 GitHub Copilot 等工具的採購與導入決策。

資產活化

學會將靜態的會議記錄與文件，轉化為動態更新的知識資產庫。

流程升級

直接解決專案中的技術債（Legacy Code）或效率瓶頸，看見即時成效。

Agent 思維

團隊不再只是工具使用者，而是學會「設計腳本讓 AI 操作工具」的架構師。
